# Security policy

## Reporting a vulnerability in this repository

If you find a security problem in this repository itself (for example in the
CI workflow or scripts), please report it privately through GitHub's
**Report a vulnerability** button on the repository's Security tab, rather
than opening a public issue.

## Scope

- A rule that misses a vulnerability or reports a false positive is a
  quality issue, not a security vulnerability in this project. Please open a
  normal issue.
- Vulnerabilities found in *other* applications using these rules should be
  reported to those applications' maintainers.

## Responsible use

The rules and examples are intended for code you own or are authorised to
assess. The vulnerable examples are deliberately insecure and must not be
deployed.
